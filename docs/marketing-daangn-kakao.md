# 학원콕 당근 광고 및 카카오톡 웰컴 상담 질문

**문서 상태:** 운영 초안 v2 — 여름방학 직후 내신 대비 시즌

**작성일:** 2026-08-19

**목적:** 여름방학이 끝나고 학교별 내신 대비가 시작되는 시점에 하남 미사 학부모를 대상으로, 현재 공개된 학원콕 랜딩의 가치인 **상담 전 질문**과 **1분 학원 점검**으로 유입시키고 카카오톡 채널에서 국어·영어·수학별 상담 준비 질문을 제공한다.

> **현재 공개 범위:** 학원콕은 정식 출시 전의 소개용 랜딩이다. 지금 제공하는 것은 상담 전 확인 질문과 1분 학원 점검이며, 등록 전 맞춤 추천은 정식 출시 후 제공 예정이다. 따라서 아래 문구는 실제 학원 추천·상담 연결·성적 향상을 현재형으로 약속하지 않는다. [1] [2]

## 1. 메시지 전략

여름방학이 끝나면 방학 동안의 학습 흐름을 내신 대비와 연결해야 하는 시점이 된다. 재원 가정에는 ‘지금 학원을 바꿔야 한다’는 불안을 만들기보다, 현재 학원이 학교별 내신 범위·서술형·오답 관리까지 아이에게 맞게 준비할 수 있는지 **점검**할 명분을 제공한다. 이전 고려 가정에는 급하게 옮기라고 압박하기보다, 새 학원이 내신 대비를 어떤 기준과 일정으로 운영하는지 상담에서 **확인**할 기준을 정리하도록 돕는다.

| 구분 | 대상 1: 현재 학원을 다니는 자녀의 학부모 | 대상 2: 학원 이전을 고민하는 학부모 |
|---|---|---|
| 핵심 상황 | 수업 수준·관리·분위기가 아이에게 맞는지 확신이 부족하다. | 현재 학원의 아쉬움은 있지만, 다음 선택의 기준이 정리되지 않았다. |
| 광고의 첫 약속 | **내신 대비 전 1분 학원 점검**으로 현재 수업과 관리가 시험 준비에 맞는지 살핀다. | **내신 상담 전 질문**으로 새 학원의 시험 대비 방식과 이전 기준을 정리한다. |
| 권장 착지 | `/check` | `/checklists` |
| 주 CTA | `1분 학원 점검하기` | `상담 전 질문 보기` |
| 카카오톡 후속 가치 | 현재 학원 또는 다음 학원 상담 때 활용할 질문을 제공한다. | 현재 문제와 다음 학원에 꼭 확인할 항목을 구분해 준다. |
| 피해야 할 표현 | “지금 학원이 문제입니다”, “무조건 바꾸세요”, 성적 보장 | “바로 옮기세요”, 타 학원 비방, 최고의 학원·확정 추천 |

서비스의 현재 공개 헤드라인인 **“학원을 알아볼 때도, 다니는 동안에도 우리 아이에게 맞는 선택을 돕습니다”**와 일관되게, 모든 광고는 아이의 상황을 먼저 살피는 차분한 존댓말을 사용한다. [1]

## 2. 당근 광고 공통 운영 원칙

당근은 광고 소재, 연결 화면, 광고주 정보 사이의 유효성·적합성과 서로의 연관성을 심사한다. 허위·과장, 검증되지 않은 보장·추천, 근거 없는 최상급 표현은 제한될 수 있으므로 본문과 착지 페이지가 같은 약속을 해야 한다. [3]

| 항목 | 적용 원칙 |
|---|---|
| 문구와 착지의 일치 | `1분 점검` 광고는 `/check`로, `상담 전 질문` 광고는 `/checklists`로 연결한다. ‘맞춤 추천’, ‘3개 학원 추천’은 정식 출시 전 광고의 현재형 약속으로 쓰지 않는다. |
| 사실성 | 미사 지역 등록 학원·교습소 410곳이라는 수치는 공개 화면에도 제시되어 있으나, 추천 정확도·성적 개선·학원 품질을 보증하는 근거로 확장하지 않는다. [1] |
| 광고 소재 | 네이티브 광고는 실제와 가까운 자연스러운 사진, 이미지 안의 최소 텍스트, 이해하기 쉬운 제목을 권장한다. 본문에서 강조한 질문·점검 가치를 제목으로 반복한다. [4] |
| 테스트 | 세그먼트별로 아래 A~E의 5개 소재를 같은 착지와 묶어 테스트한다. 동일 광고그룹 안에 여러 소재를 두고 반응을 비교하는 방식이 권장된다. [4] |
| 표현 금지 | `성적 보장`, `무조건 성적 상승`, `미사 1등`, `최고`, `확정 추천`, `지금 학원이 틀렸다`, 다른 학원과의 비교·비방은 사용하지 않는다. [3] |

## 5. 도발적 테스트 광고군

도발성은 학부모의 불안을 키우는 대신, 평소 지나치기 쉬운 질문을 정면으로 던지는 방식으로 사용한다. 광고 제목은 날카롭게 쓰되 본문은 **학교 시험 범위·서술형·오답·보강·담당 강사 소통**처럼 실제 상담에서 확인할 수 있는 항목으로 이어지게 한다. 이렇게 하면 클릭을 유도하면서도 학원콕이 현재 제공하는 ‘상담 전 질문’과 ‘1분 학원 점검’의 범위를 벗어나지 않는다.

### 광고 심사 전 주의 문구

`내신 망칩니다`, `지금 학원은 틀렸습니다`, `무조건 성적이 오릅니다`, `이 학원으로 바꾸세요`와 같은 표현은 사용하지 않는다. 도발성은 **결론을 단정하는 방식**이 아니라, 학부모가 아직 확인하지 않은 핵심 질문을 제시하는 방식으로 유지한다. 당근은 광고 문구와 랜딩페이지의 사실성·연관성을 심사하므로, 광고 제목의 문제 제기는 `/check` 또는 `/checklists`에서 실제 확인 항목으로 이어져야 한다. [3]

## 6. 카카오톡 웰컴 메시지 — 공통 첫 메시지

다음 문구는 카카오톡 채널을 추가한 직후 자동으로 보내는 기본 웰컴 메시지다. 한 번에 모든 질문을 보내지 않고, 사용자가 숫자로 선택한 과목에 맞는 메시지를 이어 보내는 흐름을 권장한다. 학교명·자녀 실명·연락처·정확한 성적은 첫 메시지에서 요구하지 않는다.

> 안녕하세요. **하남 미사 학부모를 위한 학원 선택 가이드, 학원콕**입니다.
>
> 여름방학이 끝나고 내신 대비가 시작되는 시기입니다. 학원을 처음 알아보실 때도, 지금 다니는 학원을 점검하거나 옮기기 전에도 **학교 시험 준비에 대해 상담에서 확인할 질문**을 정리해 드립니다.
>
> 먼저 필요한 항목의 번호를 답장해 주세요.
>
> `1. 국어`  `2. 영어`  `3. 수학`  `4. 현재 학원 점검`  `5. 학원 이전 준비`
>
> 현재 학원콕은 정식 출시 전입니다. 지금은 상담 전 질문과 1분 학원 점검을 이용하실 수 있으며, 등록 전 맞춤 추천은 정식 출시 후 제공될 예정입니다.

### 공통 상담 질문 — 과목 선택 전 먼저 확인

공통 질문은 국어·영어·수학 중 어떤 과목을 선택하든 먼저 확인한다. 그래야 과목별 질문이 아이의 실제 상황과 내신 일정에 맞게 이어진다. 답변하기 어려운 항목은 건너뛸 수 있게 안내하고, 이미 답한 내용은 다시 묻지 않는다.

> 내신 대비 상담을 아이 상황에 맞게 정리해 드릴게요. 아래 질문에 답장 가능한 것만 편하게 적어 주세요. 학교명이나 자녀 실명, 정확한 성적은 적지 않으셔도 됩니다.

| 순서 | 먼저 확인할 공통 질문 | 답변 예시 |
|---:|---|---|
| 1 | 아이는 현재 몇 학년인가요? | `중2`, `고1` |
| 2 | 지금 학원 상황은 어디에 가깝나요? | `처음 알아보는 중 / 현재 다니는 중 / 옮길지 고민 중` |
| 3 | 이번 내신에서 가장 신경 쓰이는 과목은 무엇인가요? | `국어`, `영어`, `수학`, `아직 모르겠어요` |
| 4 | 이번 시험에서 특히 확인하고 싶은 부분은 무엇인가요? | `교과서·부교재 / 서술형 / 문법·개념 / 독해·문제풀이 / 오답 관리 / 시험 일정` |
| 5 | 현재 가장 답답한 점은 무엇인가요? | `수업을 따라가는지 모르겠어요 / 오답 관리가 아쉬워요 / 내신 계획을 모르겠어요 / 아이가 질문을 못 해요 / 특별한 고민은 없어요` |
| 6 | 학원을 선택하거나 점검할 때 가장 중요한 기준은 무엇인가요? | `수준 적합도 / 내신 관리 / 숙제·오답 / 수업 분위기 / 시간·통학 / 보강·소통` |
| 7 | 이번 상담에서 꼭 확인하고 싶은 것이 있나요? | 자유롭게 한 문장으로 답변 |

#### 답변을 쉽게 받는 실제 메시지

> 먼저 아래 형식으로 답해 주세요. 전부 답하지 않으셔도 괜찮습니다.
>
> `학년:`
>
> `현재 상황: 처음 알아보는 중 / 다니는 중 / 이전 고민`
>
> `내신에서 걱정되는 과목:`
>
> `가장 궁금한 점:`
>
> 답변해 주시면 국어·영어·수학 중 선택하신 과목에 맞춰 상담 질문을 이어서 보내드릴게요.

공통 답변이 끝난 다음에 사용자가 선택한 과목의 상세 질문을 보낸다. 예를 들어 `고1 / 다니는 중 / 영어 / 서술형과 오답 관리가 걱정돼요`라고 답하면 영어 내신 질문으로 연결한다.

## 12. 실행 전 점검표

광고를 실제 등록하기 전에는 광고 제목, 본문, 이미지, 최종 URL을 한 묶음으로 검토한다. 특히 문구가 ‘질문 정리’ 또는 ‘1분 점검’의 현재 제공 가치만 말하는지, URL이 정상 작동하는지, 이미지가 실제와 가까우며 텍스트가 과도하지 않은지 확인한다. 플랫폼의 최종 심사 결과는 보장되지 않으므로, 광고 등록 후 심사 상태와 연결 화면 변경 여부도 다시 확인한다. [3] [4]
