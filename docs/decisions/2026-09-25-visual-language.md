# 학원콕 시각 언어 — Pretendard · 덜 베이지 캔버스 · 주황은 CTA·선택만

- 날짜: 2026-09-25
- 상태: 채택
- 대체: 없음 (토큰·홈·앱 레이아웃만. 라우트·API·카피 계약·데이터 규칙은 유지)

## 계기

홈은 글만 있고 제출 전 결과물 형태가 안 보였고, 앱은 테두리 카드 두 장의 관리자
화면처럼 보였다. 제품 흐름은 맞는데 시각 언어가 토스식 한 화면 한 행동·장소 상세
위계와 멀었다. Noto Sans KR + 따뜻한 종이색(`#faf9f5`) + 주황이 배지·포커스·wash까지
반복돼 공예품 쇼핑몰·AI 마케팅에 가까워 보였다.

## 결정

- **글자:** Pretendard. 제목 600, 본문 400/500. 큰 제목만 약간 좁은 자간.
- **캔버스:** `#F7F7F5` — 종이색을 한 단계 덜 베이지로. 그림자·보조 면도 잉크에
  맞춘 차가운 따뜻한 회색.
- **주황(`#F5A623`):** primary CTA와 칩·후보·지도의 선택 상태에만. 배지·포커스
  링·히어로 wash에는 쓰지 않는다. 포커스는 잉크.
- **형태:** 카드 12px, 입력 8px, 버튼 8px. 테두리 카드 상자를 기본 컨테이너로 쓰지
  않는다. 정보가 층이 있을 때만 약한 그림자.
- **홈:** 히어로에 신뢰 문구 하나(`HERO_REASSURANCE`). CTA는 390px에서 스크롤 없이
  보이게. 바로 아래 결과물 한 칸(역할만 — 가짜 학원 상호·스크린샷 금지). 출시 전·
  중개 없음 고지(`HEADER_STATUS_NOTICE`)는 삭제하지 않고 히어로 아래로 내린다.
- **앱:** 제출 전 좁은 한 열(상황·학년·과목 우선, 학교·태그 접힘). 제출 후 상담
  질문 → 후보. 데스크톱에서만 지도 옆 고정. 모바일 순서 입력 → 질문 → 후보 → 지도.
  후보 카드는 이름·과목 → 이유 → 주소·확인일 → 전화·상세·길찾기. 근거 토글은 첫
  시선 밖. 로딩은 카드형 스켈레톤, 빈 결과는 검색으로 가는 한 문장.

토큰·테마 문서: [`docs/design/theme.md`](../design/theme.md).

## 바꾸지 않은 것

- `/` → `/app` CTA, 폼 필드 이름·순서, 클릭 이벤트 이름, API 계약
- 카피 계약(확인해 볼 후보·상담 질문·직접 확인. 순위·별점·중개·score 표시 없음)
- 미확인 사실은 `null` — 휴리스틱·가짜 학원으로 채우지 않음
- `docs/api.md` (외부 동작 변경 없음)

## 하지 않은 것

- 디자인 시스템 패키지 도입, 보라 그라데이션 AI 랜딩, 별점·랭킹 UI
- 홈에 가짜 학원 카드·div 스크린샷
