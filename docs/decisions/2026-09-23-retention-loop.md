# 2026-09-23 — 학부모 학습 점검 반복 루프 검증

## 상태

- 상태: 승인된 사업전략 계획에 따른 검증 결정
- 결정권자: Founder
- 범위: 반복 사용·제품 확장 순서
- 관련 문서: `docs/project.md`, `docs/roadmap.md`, `docs/business-model-canvas.md`, `research/experiments/retention-loop-options.md`, `research/experiments/30-day-business-validation.md`

## 문제

학원 찾기와 학원 상담은 고관여이지만 저빈도 과업일 수 있다. 따라서 학원 검색 결과만으로는 반복 사용과 지불 가능성을 만들기 어렵다. 반면 학부모는 시험, 숙제·오답, 질문 대응, 보강, 상담, 아이의 학원 적응처럼 학원과 학습 상태를 확인해야 하는 사건을 평소에도 경험한다.

이 사건을 제품 기능으로 확대할 때 아이나 학원의 품질을 점수화하거나, 근거 없는 학습 진단을 제공하면 학원콕의 사실·미확인 항목 분리 원칙과 충돌한다. 반복성을 위해 불안을 자극하는 알림, 연속 방문, 커뮤니티, 일반 콘텐츠를 먼저 도입하는 것도 현재 근거가 없다.

## 결정

1. 반복 사용의 1순위 제품 가설을 **학부모 학습 점검**으로 둔다.
2. 핵심 루프는 `점검 → 질문 → 직접 확인 → 다음 점검`으로 정의한다.
3. 점검 결과는 상태 점수·학원 품질 등급·성적 예측이 아니라 `확인할 사실`, `아이와 학원에 물어볼 질문`, `다음 확인 시점`으로 구성한다.
4. 사용자는 자녀 실명·성적표·상세 상담 원문을 입력하지 않아도 이용할 수 있어야 한다. 초기 피드백은 `확인함`, `답변 받음`, `아직 미확인` 같은 최소 상태로 제한한다.
5. 구현보다 검증을 먼저 한다. 8–10명 학부모에게 최근 30일 반복 사건을 회고시키고 7일 미니 다이어리와 수동 질문 카드로 실제 질문 사용과 두 번째 점검을 확인한다.
6. 저장·알림·상담 후속 보드는 반복 행동이 확인된 이후에만 검토한다. 첫 단계는 로그인·푸시 없이 질문 복사·내보내기·수동 재방문으로 검증한다.
7. 두 번째 방문이 약하고 질문 사용만 강하면 주간 습관 서비스가 아니라 시험·상담 기반 사건형 도구로 포지셔닝한다.
8. 반복 사건·질문 사용·두 번째 방문이 모두 약하면 기능을 추가하지 않고 고객·문제 정의를 다시 조사한다.
9. 반복 사용이 확인되어도 즉시 학부모 과금으로 연결하지 않는다. 무료 점검의 효용과 저장·비교·상담 후속 기능의 별도 지불 의사를 순차 검증한다.

## 검증 게이트

| 신호 | 방법 | 초기 통과 기준 |
|---|---|---|
| 반복 사건 | 최근 30일 학원·학습 확인 사건 회고 및 7일 미니 다이어리 | 3명 이상에게 공통 사건과 기존 대안의 불편이 발견됨 |
| 질문 사용 | 시험 후·숙제·오답·질문 대응·보강·상담 전 질문 카드 수동 테스트 | 참여자의 60% 이상이 질문 1개 이상을 실제 또는 예정 대화에 사용 |
| 재방문 | 첫 결과의 `아직 미확인` 항목을 다시 보여 주는 링크 | 최소 3명 이상이 자발적으로 7일 내 두 번째 점검 수행 |
| 기록 가치 | 세 상태 보드 수동 제공 | 3명 이상이 다음 행동 또는 다음 상담에서 기록을 활용 |

작은 표본의 비율은 시장 전체의 유지율로 외삽하지 않는다. 합격 기준을 통과해도 다음 단계는 작은 프로토타입이며, 데이터 품질·개인정보·신뢰 검토를 함께 진행한다.

## 하지 않는 것

학원·아이의 주간 점수와 등급, 근거 없는 학습 상태 진단, 성적 예측, 불안을 자극하는 매일 알림·연속 방문, 후기 커뮤니티, 일반 교육 콘텐츠 공장, 학원에 부모 기록을 자동 전달하는 리드 기능은 이 검증 범위에 포함하지 않는다.

## 다음 행동

Founder 승인 후 첫 실행은 8–10명 학부모의 반복 사건 인터뷰와 7일 미니 다이어리다. 인터뷰에서는 “매일 쓸 것인가”를 묻지 않고 최근 실제 날짜·상황·대안·질문·확인 행동을 복원한다. 반복 사건이 확인되면 상황별 질문 카드를 수동 제공하고, 48시간 후 질문 사용과 7일 후 두 번째 점검을 확인한다.
